ตั้งค่าการเชื่อมต่อ Google Sheets

ทำครั้งเดียว — ข้อมูลจะแชร์ได้ทุกคน

1สร้าง Google Sheets + Apps Script
  1. เปิด sheets.google.com → สร้าง Spreadsheet ใหม่
  2. ตั้งชื่อ เช่น Manikin Service Records
  3. คลิกเมนู Extensions → Apps Script
  4. ลบโค้ดเดิมทั้งหมด แล้ว
    วางโค้ดด้านล่างนี้
2Deploy เป็น Web App
  1. ใน Apps Script คลิก Deploy → New deployment
  2. Type: Web app
  3. Execute as: Me
  4. Who has access: Anyone
  5. คลิก Deploy → Copy URL ที่ได้
3ใส่ URL ของ Web App
วาง Web App URL ที่ได้จาก Step 2 ด้านล่าง
URL ไม่ถูกต้อง กรุณาตรวจสอบ
